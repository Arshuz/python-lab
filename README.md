# Python & Git Practice Labs

A hands-on repository dedicated to learning Python programming while practicing version control workflows using Git.

## 📌 Project Overview

This repository serves as a personal sandbox to build dual proficiency in core Python concepts and standard Git practices simultaneously. Each entry consists of small Python scripts or functions paired with structured, conventional Git commits.

## 🎯 Learning Objectives

- **Python**: Master key programming fundamentals including data types, functions, control structures, and module management.
- **Git**: Build habit-level familiarity with version control workflows (staging, committing, branching, merging, and writing clean commit histories).

## 📜 Introduction to Python Files

- The "testing.py" is a kitchen to test how bad each other Python files are.
- The other python files has functions as per their names.

## 🛠️ Tech Stack & Tools

- **Language**: Python 3.x
- **Version Control**: Git
- **Editor**: Visual Studio Code / Terminal CLI
